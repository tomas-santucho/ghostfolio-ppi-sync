# v0.3.0 issues 9 and 10 delivery

## Issue 9 — configurable Ghostfolio batch size

- Added `GHOSTFOLIO_BATCH_SIZE`, defaulting to `100`.
- Validates a strict positive integer from `1` to `500`.
- Keeps activity ordering deterministic across configured batches.
- Batch errors now report the batch number, inclusive activity range, actual size, completed count, and failed count.
- Fingerprints preserve idempotency when rerunning after an interrupted import.

## Issue 10 — PPI quota exhaustion recovery

- Treats PPI HTTP `429` explicitly as quota/rate-limit exhaustion.
- Stops with an incomplete-history error and a nonzero exit code.
- Makes no Ghostfolio read or import attempt if the initial PPI history request is rate limited.
- Documents waiting for the quota reset and rerunning the same controlled range; fingerprints prevent duplicates after resumption.

## Verification

The mocked test suite covers default and invalid batch sizes, deterministic multi-batch ordering, a configured middle-batch failure, initial PPI quota exhaustion without Ghostfolio writes, and idempotent resumption.
