# v0.3.0 issues 7 and 8 delivery

## Issue 7 — actionable report and reconciliation

- Added fetched, mapped, imported, duplicates, unsupported, validation-failed, and HTTP-failed categories.
- Added redaction-safe source and activity fingerprints for skipped and failed records.
- Added concrete type/reason warnings for every deliberate skip.
- Made validation and import failures terminate with a nonzero process exit after printing the partial report.
- Preserved dry-run classification and reconciliation behavior without writing persistent Ghostfolio data.

## Issue 8 — retries and partial-import recovery

- Added bounded retries for connection failures, `408`, `5xx`, and Ghostfolio `429` responses.
- Honors `Retry-After` when supplied.
- Stops immediately on PPI `429`, marking history as incomplete.
- Does not retry non-transient `4xx` validation errors.
- Reports failed Ghostfolio batch number, affected activity range, completed count, and failed count; idempotent fingerprints make reruns safe.

## Verification

`bun run typecheck`, `bun run lint`, and `bun test` pass. The suite includes mocked connection failures, `Retry-After`, PPI rate limits, non-retryable validation errors, validation-report counts, safe identifiers, and partial batch recovery.
