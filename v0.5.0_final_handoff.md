## Cash profiles and safe configuration

Create and retain these distinct Ghostfolio manual profiles: `GF_PPI_CASH_ARS`, `GF_PPI_CASH_USD_GLOBAL`, `GF_PPI_CASH_USD_MEP`, and `GF_PPI_CASH_USD_CCL`. In Ghostfolio: **Add asset profile** → **Add manually**; choose the required currency and **Cash** when available. When the UI already supplies `GF_`, enter only the remainder (for example, `PPI_CASH_ARS`). Do not create opening BUY activities.

Use this non-secret configuration shape:

```dotenv
PPI_ACCOUNT_IDS=$PPI_ACCOUNT_ID,177551
PPI_CASH_ASSETS={"ARS":"GF_PPI_CASH_ARS","USD_GLOBAL":"GF_PPI_CASH_USD_GLOBAL","USD_MEP":"GF_PPI_CASH_USD_MEP","USD_CCL":"GF_PPI_CASH_USD_CCL"}
PPI_CASH_ACTIVITY_IMPORT=false
```

The first account remains referenced through the existing environment variable so this document never contains it. Four profiles were accepted by a Ghostfolio dry-run with no persisted activity.
